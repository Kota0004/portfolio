みずみち — 冠水道路アラート

試作・公開中

大雨のときに、冠水しやすい道路の危険度を地図で知らせる防災アプリです。

きっかけ
2026年8月の千葉豪雨で、冠水に気づかず進入した車が多数動けなくなったこと。
できること
  • 関東の1都6県（東京・埼玉・神奈川・栃木・千葉・茨城・群馬）の道路冠水注意箇所 827 か所を地図に載せています。
  • 気象庁アメダスの雨量を GitHub Actions が毎時自動で取り込み、地点ごとの冠水しやすさ（閾値）と比べて、危険度を色分けします。
  • 827 か所のうち 581 か所は資料に番地が無く、位置は市区町村レベルの推定です。こうした地点では地点の警報を鳴らさず、区別して表示しています。
品質の確かめ方
  • 危険度の計算は Python とブラウザ（JavaScript）の2か所にあり、2,700 通りの入力で結果が一致することを自動テストで確かめています。
  • ブラウザでの動作も自動で検証しています。

RoomRadar — 空き教室検索

大学非公式・テスト運用中

日本大学理工学部の空き教室を探せる Web サービスです。大学が公開している時間割から、授業の入っていない教室を表示します。

大学非公式・テスト運用中のサービスです。大学公式のサービスではありません。

工夫したこと
利用者が「使用中」を報告でき、2人以上が報告すると「使用中の可能性」と表示します。時間割だけでは分からない実態を補うためです。

デモ作品

お作りできるものの見本です。どちらも架空のデータで動きます。入力したデータや読み込んだファイルは、外部に送られません（ブラウザの中だけで処理します）。

予約フォーム

空き枠を見ながら予約できるフォームと、受け付けた予約を確かめる管理画面のセットです。

  • 空き枠の表示
  • 入力内容のチェック
  • 送信前の確認画面
  • 二重予約の防止
  • 管理画面での一覧と CSV 書き出し

CSV 集計ツール

  • CSV の読み込み（Excel で保存した Shift_JIS の CSV も読めます）
  • 列を選んで合計・平均・件数などを集計
  • 集計結果のグラフ表示
  • 結果を CSV で保存

できること

次のようなものをお作りします。

A予約・申込フォームなど小さな Web ツール

申込をメールで受けて手作業でまとめている、といった作業を、フォームと一覧ページに置きかえます。

BExcel・スプレッドシートの作業の自動化

毎回同じ手順でくり返している表計算の作業を、自動で済むようにします。
